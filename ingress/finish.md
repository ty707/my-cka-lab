## 📝 架构复盘与最佳实践

回顾一下你在本次实战中完成的核心配置：

1. **七层路由 (L7 Routing)**：利用 `host` 规则实现了基于域名的虚拟主机路由，避免了为每个服务单独申请公网 LoadBalancer 的昂贵成本。
2. **声明式 API 规范**：你使用了 `networking.k8s.io/v1` 这一最新且稳定的 API 版本，完全摒弃了早期废弃的注解（Annotations）方式，符合云原生标准。

💡 **生产环境进阶建议**：
在生产环境中，你可能还需要在 Ingress 之上配置 **Cert-Manager** 来自动签发和续期 Let's Encrypt 免费证书，实现全站 HTTPS 加密；同时可以引入 **ExternalDNS**，让域名解析自动跟随 Ingress 的变化，实现真正的全自动化网关管理。

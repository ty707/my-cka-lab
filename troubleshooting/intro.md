# 🚨 模拟演练：K8s 控制平面灾难恢复

**演练背景**：
在一场突发的物理机迁移事故中，你的 K8s 集群控制平面全面瘫痪。API Server 无法响应，Scheduler 无法调度，甚至业务层的路由也出现了断裂。

**当前环境状态**：
- 本实验后台已经自动模拟了**三个连环故障**（API Server 配置损坏、Scheduler 资源溢出、Service 路由异常）。
- 当前集群处于部分失联状态。

**你的目标**：
1. 扮演 SRE 角色，通过排查静态 Pod 的日志和配置文件，定位核心组件故障。
2. 不要依赖外部脚本，纯手工修复被篡改的 YAML 配置。
3. 恢复集群通信，并修复业务层的网络访问。

请在右侧终端开始你的排错操作，按照左侧步骤指引逐步恢复集群。

# 📈 实战演练：高并发流量下的自动弹性伸缩

**演练背景**：
你的团队刚刚上线了一个核心的 Web 服务（`apache-server`），为了迎接即将到来的双十一大促，架构组要求必须实现基于 CPU 指标的自动扩缩容，以应对不可预知的流量洪峰。

**当前环境信息**：
- 命名空间：`autoscale`
- 目标应用：`apache-server` (基于 Nginx 镜像)
- 监控组件：`metrics-server` 已在后台自动部署并运行

**你的目标**：
1. **创建 HPA**：手写标准的 YAML 清单，为应用绑定自动扩缩容策略。
2. **模拟压测**：在终端启动压测脚本，模拟高并发访问。
3. **观察弹性**：见证 HPA 在流量高峰期自动增加 Pod，保障业务高可用。

准备好后，请点击右侧终端，按照步骤开始你的云原生实战！
